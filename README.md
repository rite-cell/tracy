# Tracy

Min träningslogg: styrkepass med set, reps och vikt, andra pass som yoga och flexcore, kroppsvikt och schema.

Sajten ligger på https://tracy.teroni.se och hostas med GitHub Pages.

## Filer

- `index.html` – hela appen
- `manifest.json`, `icon.svg`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png` – namn och ikon när appen läggs på hemskärmen
- `CNAME` – kopplar GitHub Pages till tracy.teroni.se
- `.nojekyll` – gör att GitHub Pages visar filerna som de är

## Data

All data sparas i webbläsaren på den enhet du använder. Spara en säkerhetskopia under Schema → Säkerhetskopia då och då.
